# 🚗 Car Price Prediction

## 📌 Project Overview  
This project is an **ML-powered web application** that predicts the **selling price of a car** based on several features such as fuel type, years of service, showroom price, number of previous owners, kilometers driven, seller type, and transmission type. The model provides users with an estimated price before selling their car.

The application is built using **Flask** for the backend, **Random Forest Regression** for prediction, and a clean, responsive UI using **HTML & CSS**.

---

## 🚀 Features  
✅ **Accurate Price Prediction** using a trained ML model  
✅ **Interactive Web UI** for easy input and results display  
✅ **Dropdown Selections** for car model, fuel type, transmission, and seller type  
✅ **Trained ML Model Integrated** using `joblib`  
✅ **Deployed using Flask**, making it accessible via a web browser

## 📌 Installation Guide  

### 1. **Clone the Repository:**  

git clone https://github.com/your-username/car-price-prediction.git

cd car-price-prediction

### 2. ** Run the Application:**
python app.py

### 3. **Model Training:**
The Random Forest Regression model was trained using Scikit-learn.
The trained model was saved using joblib for deployment in Flask.

### 4. **🎯How It Works:**
1️⃣ User enters car details in the web form
2️⃣ The input is processed and sent to the trained ML model
3️⃣ The model predicts the estimated selling price
4️⃣ The result is displayed on the web page

The Car Price Prediction project is a machine learning-based  system that helps users estimate the resale value of a used car
